# 🌤️ Weather Forecast App

A modern Android weather app that provides real-time weather updates and forecasts based on your location. Built using Kotlin and Jetpack Compose with MVVM architecture.

## 📱 Features

- 🌍 Location-based weather forecast
- 🔔 Weather alerts
- 📶 Offline support with Room database
- 🧭 Clean architecture using MVVM
- 🔄 Background updates with WorkManager

## 🛠️ Tech Stack

- **Language:** Kotlin  
- **UI:** Jetpack Compose  
- **Architecture:** MVVM  
- **Networking:** Retrofit  
- **Local Storage:** Room  
- **Background Tasks:** WorkManager  
- **Coroutines** for async tasks
